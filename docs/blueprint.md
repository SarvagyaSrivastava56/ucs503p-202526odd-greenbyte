# **App Name**: UniConnect

## Core Features:

- Authentication: Secure user authentication with Google and email/password options, managed via Firebase Auth. Includes student/admin roles.
- Event Listings: Browse events with search and filter options (category, date, location).
- Event Details & RSVP: View detailed event information and RSVP using Firestore. Integrate with Google Calendar and show a live participant counter.
- Admin Event Management: In-app admin dashboard for creating, editing, and deleting events, including poster uploads via Firebase Storage.
- Community Chat: Per-event chat rooms managed with Firestore.
- Trending & Personalization: Display trending events and offer personalized event recommendations based on user RSVPs and favorites, possibly using a tool for basic analysis.
- Push Notifications: Send event reminders and custom announcements via Firebase Cloud Messaging.

## Style Guidelines:

- Primary color: A vibrant orange (#FF7043) to capture the energy and excitement of campus life.
- Background color: Light peach (#FBE9E7), a soft and inviting background that maintains brightness.
- Accent color: Deep red-orange (#E64A19), a contrasting hue to highlight key actions and elements.
- Headline font: 'Poppins', a geometric sans-serif for a modern, fashionable, avant-garde look; body text: 'PT Sans', a humanist sans-serif that combines a modern look and a little warmth or personality.
- Use Material Design icons for a consistent and recognizable look.
- Employ card-based layouts with rounded corners and subtle drop shadows for a modern, clean interface. Use glassmorphism on event cards for a premium feel.
- Incorporate smooth hero animations and a confetti animation on successful RSVP for a delightful user experience.
